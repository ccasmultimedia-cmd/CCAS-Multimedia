Les raccourcis clavier

Découvrez des raccourcis simples pour travailler plus rapidement sur ordinateur.

Les raccourcis à connaître

Un raccourci clavier permet d'effectuer une action rapidement en utilisant plusieurs touches du clavier.

Ctrl + A Tout sélectionner
Ctrl + C Copier
Ctrl + V Coller
Ctrl + X Couper
Ctrl + Z Annuler
Défi 1

Quel raccourci utiliser ?

Vous voulez copier un texte. Quel raccourci devez-vous utiliser ?

Défi 2

Tout sélectionner

Cliquez dans la zone ci-dessous puis essayez réellement : Ctrl + A.

Défi 3

Copier et coller

Copiez le texte suivant :

Je progresse en pratiquant régulièrement.

Puis collez-le dans cette zone :

Défi 4

Couper et déplacer

Déplacez le mot rapidement pour obtenir :

Je peux rapidement utiliser les raccourcis clavier.

Défi 5

Annuler une erreur

Essayez cette manipulation :

  1. Cliquez dans la zone.
  2. Supprimez quelques mots.
  3. Utilisez Ctrl + Z.

Astuce

Vous n'avez pas besoin de retenir tous les raccourcis immédiatement. Commencez par Ctrl + C et Ctrl + V, puis entraînez-vous progressivement avec les autres.

Bravo !

Vous connaissez maintenant plusieurs raccourcis très utiles.
