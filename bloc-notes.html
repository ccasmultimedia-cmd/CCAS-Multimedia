📋 Bloc-notes

Écrivez et mettez votre texte en forme facilement

💡 Comment ça marche ?
Écrivez votre texte ci-dessous. Vous pouvez ensuite sélectionner un mot ou une phrase et utiliser les boutons de la barre d'outils pour le mettre en forme.
📝 0 mot(s)
🔤 0 caractère(s)

🖱️ Pour mettre un mot en gras

Sélectionnez le mot avec la souris, puis cliquez sur G. Le mot devient immédiatement en gras.

🎨 Pour changer une couleur

Sélectionnez votre texte puis cliquez sur 🎨. Choisissez ensuite la couleur souhaitée.

🖍️ Pour surligner

Sélectionnez un passage puis cliquez sur 🖍️. Vous pouvez choisir la couleur du surlignage.

↶ Une erreur ?

Pas de problème ! Utilisez ↶ pour annuler votre dernière action et ↷ pour la rétablir.

💡 Bon à savoir

Le bouton 💾 Enregistrer conserve votre texte dans le navigateur de cet appareil. Rien n'est envoyé sur Internet. Vous pourrez utiliser 📂 Rouvrir mon texte pour le retrouver plus tard sur ce même navigateur.
