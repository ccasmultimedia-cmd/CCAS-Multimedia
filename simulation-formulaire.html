Simulation : remplir un formulaire

Entraînez-vous à remplir un formulaire sur Internet dans un environnement sans risque.

Votre mission

Vous allez remplir un faux formulaire de demande de renseignements.

Le but est de vous entraîner à :

  • lire les différentes questions ;
  • écrire des informations dans les cases ;
  • choisir une réponse dans une liste ;
  • cocher une case ;
  • envoyer un formulaire.

Important : ce formulaire est entièrement fictif. Aucune donnée n'est envoyée sur Internet.

Il manque encore certaines informations. Vérifiez les champs indiqués puis réessayez.

Quelques conseils

  • Prenez le temps de lire chaque question avant de répondre.
  • Les champs avec une étoile sont généralement obligatoires.
  • Une liste déroulante permet de choisir une réponse proposée.
  • Une case à cocher permet généralement de confirmer quelque chose.
  • Avant de valider un formulaire, prenez toujours quelques secondes pour vérifier vos informations.
