Couper et déplacer du texte

Apprenez à déplacer du texte d'un endroit à un autre.

Quelle est la différence entre Copier et Couper ?

Copier laisse le texte à son emplacement d'origine.

Couper retire le texte de son emplacement pour pouvoir le déplacer ailleurs.

Pour couper du texte, utilisez :

Ctrl + X

Pour le placer ailleurs, utilisez :

Ctrl + V

Ctrl + X Couper
Ctrl + V Coller
Exercice 1

Déplacer une phrase

Dans la zone ci-dessous, sélectionnez la deuxième phrase. Coupez-la avec Ctrl + X, puis placez le curseur au début et collez-la avec Ctrl + V.

Exercice 2

Remettre les phrases dans le bon ordre

Déplacez les phrases pour obtenir cet ordre :

  1. Je sélectionne le texte.
  2. Je coupe avec Ctrl + X.
  3. Je place le curseur.
  4. Je colle avec Ctrl + V.
Exercice 3

Déplacer un mot

Réorganisez la phrase pour obtenir :

J'apprends tranquillement à utiliser mon ordinateur.

Conseil important

Si vous vous trompez après avoir coupé un texte, pas de panique ! Vous pouvez souvent utiliser :

Ctrl + Z

Ce raccourci permet généralement d'annuler la dernière action.
