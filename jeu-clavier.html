Quelques touches importantes à connaître

  • Maj ⇧ : permet d'écrire une majuscule temporairement.
  • Verr. Maj : permet d'écrire plusieurs majuscules.
  • Retour arrière : efface le caractère situé avant le curseur.
  • Suppr : efface le caractère situé après le curseur.
  • Entrée : permet notamment de passer à la ligne.
  • Espace : crée un espace entre les mots.
  • Alt Gr : permet d'accéder à certains caractères spéciaux.
  • Ctrl : est utilisé avec d'autres touches pour les raccourcis.
