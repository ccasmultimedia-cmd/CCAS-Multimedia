Exercice Copier-Coller

Entraînez-vous avec le clavier et la souris, sur du texte puis sur des fichiers.

Le copier-coller est une fonction très pratique de l'ordinateur. Il permet de dupliquer un texte ou un fichier sans avoir à tout refaire.

Les exercices commencent simplement puis deviennent progressivement plus proches de situations que vous pourrez rencontrer sur votre ordinateur.

Deux façons de faire

Tout au long de cet exercice, vous pouvez choisir la méthode qui vous convient. Vous pouvez aussi profiter des différentes missions pour vous entraîner volontairement avec les deux méthodes.

Avec le clavier Sélectionnez l'élément puis utilisez :

Ctrl + C pour copier

puis

Ctrl + V pour coller.
Avec la souris Sélectionnez l'élément puis faites :

clic droit → Copier

puis dans l'emplacement de destination :

clic droit → Coller.
Ctrl + C Copier Place l'élément sélectionné dans le presse-papiers.
Ctrl + V Coller Place la copie à l'endroit choisi.

Partie 2 — Copier-coller des fichiers

Maintenant, nous allons passer à une situation très courante : copier un fichier d'un dossier vers un autre dossier.

Ces explorateurs sont des simulations. Aucun véritable fichier de votre ordinateur ne sera modifié.

Pour les missions suivantes, vous pouvez utiliser Ctrl+C / Ctrl+V ou clic droit → Copier / Coller.

Bravo !

Si vous avez réussi les différentes missions, vous savez maintenant utiliser le copier-coller sur du texte et sur des fichiers.

Le plus important est de savoir qu'il existe plusieurs façons de faire. Vous pouvez utiliser le clavier, la souris, ou choisir la méthode qui vous semble la plus confortable selon la situation.

N'hésitez pas à refaire certaines missions avec l'autre méthode : c'est justement en pratiquant que les gestes deviennent naturels.
