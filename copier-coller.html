Copier-coller et sélection multiple

Entraînez-vous à copier, coller et sélectionner plusieurs éléments.

À quoi sert cet exercice ?

Le copier-coller est une fonction très pratique de l'ordinateur. Il permet de dupliquer rapidement du texte ou des fichiers.

Dans la dernière partie, nous apprendrons également à sélectionner plusieurs fichiers.

Les exercices sont volontairement progressifs. Vous pouvez prendre votre temps et refaire une mission plusieurs fois.

Deux façons de faire

Pendant les exercices, vous pouvez choisir la méthode qui vous convient. Vous pouvez également profiter des différentes missions pour vous entraîner avec les deux méthodes.

Avec le clavier Sélectionnez l'élément puis utilisez :

Ctrl + C pour copier.

Puis :

Ctrl + V pour coller.
Avec la souris Sélectionnez l'élément puis :

clic droit → Copier

Puis dans la destination :

clic droit → Coller.
Ctrl + C Copier
Copier l'élément sélectionné.
Ctrl + V Coller
Coller la copie à l'endroit choisi.

Partie 3 — Sélection multiple

Cette partie est consacrée uniquement à la sélection de plusieurs éléments. Prenez votre temps : chaque méthode correspond à une situation différente.
Les trois méthodes à retenir :

Ctrl + clic : je choisis précisément plusieurs éléments.

Shift + clic : je sélectionne tout un bloc entre deux éléments.

Ctrl + A : je sélectionne tous les éléments.
Ctrl + clic Sélection précise de plusieurs fichiers, même s'ils sont séparés dans la liste.
Shift + clic Sélection d'un bloc complet entre deux fichiers.
Ctrl + A Sélection de tous les fichiers du dossier.
