Copier et coller

Entraînez-vous à sélectionner, copier et coller du texte.

Comment faire ?

Pour réaliser ces exercices :

  1. Sélectionnez le texte avec votre souris.
  2. Copiez le texte avec Ctrl + C.
  3. Cliquez dans la zone prévue.
  4. Collez le texte avec Ctrl + V.
  5. Cliquez sur « Vérifier ma réponse ».
Ctrl + C Copier
Ctrl + V Coller

Un petit conseil

Si vous préférez utiliser la souris, vous pouvez également faire un clic droit sur le texte sélectionné puis choisir « Copier ». Ensuite, faites un clic droit dans la zone de texte et choisissez « Coller ».
