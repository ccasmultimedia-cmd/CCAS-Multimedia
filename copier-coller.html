Copier et coller

Entraînez-vous à copier et coller du texte et des fichiers.

Comment faire ?

Ces exercices deviennent progressivement plus difficiles. Prenez votre temps et lisez bien chaque consigne.

  1. Sélectionnez le texte ou le fichier demandé.
  2. Copiez-le avec Ctrl + C.
  3. Cliquez à l'endroit où vous souhaitez le placer.
  4. Collez avec Ctrl + V.
  5. Pour les fichiers, vous pouvez également utiliser les boutons « Copier » et « Coller ».

Ctrl + V Coller

Un petit conseil

Pour du texte, vous pouvez utiliser Ctrl + C puis Ctrl + V.

Pour les fichiers, le principe est exactement le même : vous sélectionnez le fichier, vous le copiez, puis vous le collez dans un autre dossier.

Copier crée une copie du fichier. Le fichier original reste donc à son emplacement.
