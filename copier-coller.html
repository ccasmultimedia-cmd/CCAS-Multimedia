Copier-coller et sélection multiple

Entraînez-vous à copier, coller et sélectionner plusieurs éléments.

Comment utiliser cet exercice ?

Cet exercice vous permet de vous entraîner progressivement à utiliser le copier-coller et la sélection multiple.

Vous apprendrez d'abord à copier du texte, puis des fichiers. Ensuite, vous apprendrez différentes façons de sélectionner plusieurs fichiers.

Vous pouvez utiliser le clavier ou la souris. N'hésitez pas à refaire une mission plusieurs fois pour vous entraîner.

Deux façons de copier et coller

Pendant les exercices, vous pouvez choisir la méthode qui vous convient. Vous pouvez également profiter des missions pour vous entraîner aux deux.

Avec le clavier Sélectionnez l'élément puis utilisez :

Ctrl + C pour copier.

Puis :

Ctrl + V pour coller.
Avec la souris Sélectionnez l'élément puis faites :

clic droit → Copier

Puis dans la destination :

clic droit → Coller.
Ctrl + C Copier
Ctrl + V Coller

Partie 3 — Sélection multiple

Cette partie est consacrée uniquement à la sélection de plusieurs éléments. Prenez votre temps pour bien comprendre les trois méthodes.
Les trois méthodes à retenir :

Ctrl + clic : je choisis précisément plusieurs éléments.

Shift + clic : je sélectionne tout un bloc entre deux éléments.

Ctrl + A : je sélectionne tous les éléments de la liste.
Ctrl + clic Sélection précise de plusieurs fichiers, même lorsqu'ils sont séparés.
Shift + clic Sélection d'un bloc complet entre deux fichiers.
Ctrl + A Sélection de tous les fichiers de la liste.
