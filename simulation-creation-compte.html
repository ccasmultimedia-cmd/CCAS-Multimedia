Simulation : créer un compte

Entraînez-vous à créer un compte sur Internet dans un environnement fictif et sans risque.

Bienvenue dans cette simulation

Dans la vie quotidienne, de nombreux sites Internet demandent de créer un compte. Cette simulation vous permet de vous entraîner tranquillement avant de le faire sur un vrai site.

Important : vous ne devez utiliser aucune vraie information personnelle et rien ne sera envoyé sur Internet.

Créer votre compte

Remplissez les informations demandées pour continuer.

Pour cette simulation, utilisez une fausse adresse.
L'identifiant permettra de vous reconnaître lorsque vous vous connecterez.
Conseil :
  • Utilisez plusieurs caractères.
  • Mélangez lettres, chiffres et caractères spéciaux.
  • Évitez votre prénom ou votre date de naissance.
  • N'utilisez jamais le même mot de passe partout.

À retenir

Avant de créer un compte sur un vrai site, prenez toujours le temps de vérifier que vous êtes bien sur le bon site. Pour un exercice, utilisez uniquement des informations fictives.
